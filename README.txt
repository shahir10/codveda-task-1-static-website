MY WEBSITE - CORRECTED VERSION

1. Keep index.html, about.html, contact.html, style.css and script.js in the same folder.
2. Create a folder named "images" in that folder.
3. Put your image inside it and name the image "download.jpg".
4. Open index.html in your browser.

The contact form is only a front-end demonstration. It validates the fields and displays a message, but it does not send or store messages. To receive messages, connect it to a backend or a form service.
